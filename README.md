# Agora Website

Static multi-page website for `Agora`, the debating society of ABESEC.

## Pages

- `index.html` - homepage and society positioning
- `about.html` - identity and institutional framing
- `events.html` - term rhythm and event structure
- `join.html` - recruitment and onboarding
- `resources.html` - formats and beginner materials
- `team.html` - committee visibility
- `archive.html` - poster wall, motions, results, memory
- `contact.html` - official pathways and outreach
- `dBETA.html` - redirect to `index.html`

## Shared Assets

- `assets/css/site.css` - global design system and responsive layout
- `assets/js/site.js` - shared data, navigation behavior, and reveal effects
